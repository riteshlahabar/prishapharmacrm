# Phase 8 — hardening        2026-11-22

Tests, demo seeders, Pint, docs. How to run it: `docs/testing.md`.

## What was there
The `phase6`/`phase7` smoke scripts covered the HTTP contract, but need a live
server and seeded dev users. `tests/Feature` was Laravel's stock `ExampleTest`,
asserting `GET /` is 200 — it fails, since `/` is behind `auth`. No factories
but `UserFactory`, and no demo data.

## What landed
284 tests: one file per module surface (`CallLogApiTest`, `CallLogPanelTest`, …)
plus `ApiContractTest` for what every list shares — envelope, paging clamps,
403-vs-404, cross-app token refusal. Factories moved into the modules, wired by
`#[UseFactory]`, so a module owns its fixtures as it owns its migrations.

`DemoSeeder` (not in `DatabaseSeeder`) builds 3 regions, 3 MRs, 2 telecallers,
21 persons and three weeks of activity. Refuses to run in production.

`tests/smoke/phase8-suite.sh` is the gate: Pint, the suite, migrate + seed +
rollback, `check-docs.sh`. No server, no MySQL.

## Three holes the tests found
- **Attendance** was the only panel list reading company-wide: Visits, Calls,
  Messages and Persons used a `*ForUser` method, this one called `paginate()`.
  A telecaller granted `attendance.view` saw every rep.
- **Persons** `show`/`edit` resolved by id and never asked
  `PersonPolicy::view`, so the list's clamp was cosmetic — any telecaller
  could read any contact's mobile and address.
- **Normalisation ran after validation.** Region `code` and user `email` were
  cased in `payload()`, so `unique` checked a string that was never stored.
  MySQL's collation hid it; sqlite turned "dup" vs "DUP" into a 500.

Also: the persons `down()` dropped columns while indexes still named them —
fine on MySQL, refused by sqlite, so rollback worked on one engine only.

## Left deliberately
Report filter dropdowns list all MRs and regions regardless of territory. The
**rows** are clamped; only names leak, and the pattern is identical across
five modules, so changing it is its own task.
