# 2026-11-21 — Phase 0: foundation

- Audited all 3 repos: existing code was a generic customers/products/orders
  CRM, none of the pharma domain. Sanctum was referenced but never installed,
  so the whole API was dead; web routes had no `auth` middleware at all.
- Decisions: customers → persons, drop products/orders;
  `spatie/laravel-permission`; MySQL; docs on the code branch.
- `composer install`; required `laravel/sanctum` 4.5 + `spatie/laravel-permission` 8.5.
- MariaDB 10.11 installed in-container (MySQL-compatible) — cPanel deliberately
  NOT connected (ephemeral IP, 3306 blocked by proxy, production data risk).
  `.env` on `mysql` driver, db `prisha_pharma`; `.env.example` cPanel-shaped.
- Published + ran spatie and Sanctum migrations (`personal_access_tokens` was
  missing — Sanctum 4 does not auto-load it).
- Added `app/Core` (RepositoryInterface, Filterable, EloquentRepository,
  ApiResponse, ModuleServiceProvider) and 10 module skeletons registered
  through `config/modules.php` + `ModuleRegistrarServiceProvider`.
- Created `docs/` (index, conventions, roadmap, schema, 10 module files,
  3 API files) + `docs/check-docs.sh`.
