# 2026-11 — rotated fixes

## Reports menu invisible on an older database
`2026-11-22` The Reports menu was invisible on any database seeded before
Phase 11: the new permission rows did not exist, and `RoleSeeder` *skipped*
an existing non-admin role rather than updating it. It now **tops up** a role
with the defaults it lacks — it adds, it never syncs, so a hand-granted
permission survives. Re-run `php artisan db:seed` after any change to the
permission catalogue (`docs/modules/access.md`).

## 2026-11-24 · action-column icons
Bare `.btn-link` glyphs laid out inline: underlined, the `<form>` buttons
half a line low, `.txt-danger` (`!important`) beating delete. Now Cuba's
`.product-action` shape — a `.table-actions` flex row of 34px tiles;
`ui-actions.md`, a test. Edited CSS loads via `@assetv` (mtime) or the
browser serves its cached copy.
