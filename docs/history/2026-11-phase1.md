# 2026-11-21 — Phase 1: auth, roles, users

- `users` gained `mobile` (unique), `role`, `region_id`, `is_active`. `role` is
  nullable so pre-Phase-1 rows are not silently promoted; a role-less row is
  treated as no account. `region_id` has an index but no FK until `regions`.
- `App\Models\User` moved to `App\Modules\Users\Models\User` (+HasRoles);
  `config/auth.php`, the factory and the seeder follow it.
- Three roles, not two: `mr` exists because MRs sign into their app and the
  token ability carries the role. Only admin+telecaller reach the panel.
- 30 permissions from one `PermissionCatalog`; admin re-synced to all on every
  seed, telecaller seeded once with a baseline, mr none.
- Telecaller extras are *direct* permissions on top of the role baseline, so
  changing the baseline reaches everyone without touching individual grants.
  `grantable()` omits access/mrs/telecallers and `syncDirect` filters against
  it — a crafted POST of `access.manage` is dropped (verified).
- MR and telecaller CRUD share one `UserCrudController` and one set of views.
- Two theme bugs found while checking the new screens, both pre-existing:
  `vendors/bootstrap.css` was never linked (grid collapsed, buttons invisible),
  and the header used Bootstrap 4 `.media`/`.media-body`, making it 124px
  against the 80px `.page-body` offset and hiding each page's title.
- 45-check smoke run green: panel auth, CRUD, cross-role 404s, telecaller 403s,
  sidebar scoping, app tokens, role gating, disabled accounts, legacy routes.
